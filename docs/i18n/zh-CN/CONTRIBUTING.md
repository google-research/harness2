# 如何贡献

欢迎参与 Harness²！无论是修复问题、改进文档，还是提交新功能，我们都很期待。

## 开始之前

### 签署贡献者许可协议

提交贡献前，需要先签署
[贡献者许可协议](https://cla.developers.google.com/about)（CLA）。贡献内容的版权仍然
属于你（或你的雇主）；这份协议只是允许我们在项目中使用和分发这些内容。

如果你或当前雇主之前已经为其他项目签过 Google CLA，一般不需要重复签署。

可以前往 <https://cla.developers.google.com/> 查看签署状态，或完成新的签署。

### 阅读社区准则

本项目遵循 [Google 开源社区准则](https://opensource.google/conduct/)。

## 贡献流程

### 文档翻译

翻译文档都放在 `docs/i18n/<locale>/` 下。准备新增或更新翻译时，请先看一下
[翻译维护指南](../README.md)，里面说明了目录结构、语言代码和同步方式。

### 代码审查

所有改动都要经过代码审查，项目成员的提交也不例外。请通过 GitHub Pull Request
提交。如果还不熟悉这个流程，可以参考
[GitHub 的 Pull Request 说明](https://help.github.com/articles/about-pull-requests/)。
